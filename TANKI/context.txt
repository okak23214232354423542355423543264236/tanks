=== ЧТО ЭТО ===
2D-игра про танки в браузере. Гараж, дерево исследований,
бой (1v7, 7v7), лутбокс, читы. Управление танком сверху.

Цель проекта — масштабируемая платформа для 2500+ танков
с 7 рангами и 7+ нациями (Британия, Франция, Япония...).

=== МЕХАНИКИ ===

1. БРОНЯ ПО УГЛАМ
   - Лоб (deg>135°), борт (45–135°), корма (deg<45°)
   - Пробитие >= броня → урон проходит
   - Иначе: 10% пробить, 5% рикошет

2. ПТ-САУ (isPT=1)
   - Орудие ограничено ±10° от корпуса
   - Корпус = прицел

3. ПУЛЕМЁТ (mgOn=1)
   - Активация: SHIFT
   - Шанс пробить: броня≤1→15%, 2–3→10%, ≥4→5%
   - ±15° от корпуса, перегрев 5с → блок 5с

4. СНАЙПЕРКА (sniperOn=1)
   - Стреляет сама, свой КД
   - Урон = dmg × sniperMult
   - Пробитие 1

5. МАНЁВРЕННОСТЬ (mvr)
   - Скорость поворота корпуса
   - Башня крутится ×1.2

6. ЗАДНИЙ ХОД (rspd)
   - S на клавиатуре
   - Скорость = spd/1.5

7. ЗАДНИЙ ХОД В БОЮ (для ботов)
   - При цели < 200px — бот отъезжает назад
   - Не разворачивается (корпус-прицел остаётся на цели)


=== УПРАВЛЕНИЕ ===

S — задний ход
ЛКМ / Пробел — стрельба
SHIFT — пулемёт

=== КЛЮЧЕВЫЕ ФУНКЦИИ в game.js ===

ЗАГРУЗКА:
  loadNations()       — загрузка наций из JSON
  loadRank(nation, r) — загрузка танков ранга
  loadAllTanks()      — загрузка всех танков
  tanksOf(nation)     — список танков нации

СОХРАНЕНИЕ:
  loadSave()          — загрузка из localStorage
  save()              — сохранение в localStorage
  resetAll()          — сброс прогресса

ИНТЕРФЕЙС:
  renderNations()     — кнопки наций в гараже
  renderGarage()      — карточки танков
  renderTreeNations() — панель дерева (нации + фильтры)
  renderTree()        — отрисовка дерева
  buildTreeUSA/GER/USSR() — деревья наций
  makeNode()          — узел дерева
  arrowV()            — стрелка ⬇
  unlockTank()        — покупка танка

TTX:
  showTTX(k, e)       — тултип с ТТХ
  moveTTX(e)          — перемещение тултипа
  hideTTX()           — скрытие

ЛУТБОКС:
  openLootbox()       — открыть
  closeLootbox()      — закрыть
  spinLootbox()       — крутить
  renderLootTrack()   — отрисовать трек

ЧИТЫ:
  cheat(k)            — обработка читерских кодов
  showCheat(t)        — показать сообщение

БОЙ:
  start(mapType)      — начать бой
  toGarage()          — вернуться в гараж
  showBattleEnd(win)  — экран победы/поражения
  update()            — обновление кадра
  draw()              — отрисовка
  loop()              — игровой цикл
  shoot()             — стрельба игрока
  obsGen()            — генерация препятствий
  spawnE(), spawnAlly() — спавн юнитов
  eType(), allyType() — выбор танка врага/союзника
  eStats(), allyStats() — статы врага/союзника
  makeUnit()          — создание юнита
  unitAI(e, isEnemy)  — ИИ юнита
  moveUnit(e, t, dtP) — движение с обходом препятствий
  rayCast()           — прощупывание пути
  isFree()            — проверка точки
  calcHit(), calcMgHit() — расчёт попадания
  getArmorFromAngle() — угол попадания
  rotateTowards()     — плавный поворот
  resolveCollision()  — столкновения

ИНИЦИАЛИЗАЦИЯ:
  init()              — точка входа (в конце файла)


=== ПЕРЕМЕННЫЕ ГЛОБАЛЬНЫЕ ===
NATIONS              — объект наций { usa: {...}, ... }
T                    — объект ВСЕХ танков { T1: {...}, ... }
P                    — сохранение игрока { exp, coins, gold, unlocked, ... }
curT                 — текущий выбранный танк (ID)
curNation            — текущая нация в гараже
treeNation           — текущая нация в дереве
treeFilter           — фильтр ранга ('all' / '1' / '2' / ...)
treeView             — 'nation' / 'premium'
currentMap           — 'corridor' / 'open' / 'team7v7'
inG                  — true если идёт бой
P_                   — объект игрока в бою (x, y, a, ta, hp...)
bullets, enemies, allies, obs — массивы боя
cam                  — камера { x, y }
SK                   — ключ сохранения = 'tank2d_v57'
